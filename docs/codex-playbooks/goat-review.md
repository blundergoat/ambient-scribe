# GOAT Review

Review mode for changes in this repo.

## Severity
- MUST FIX: data loss, security, broken runtime path, or clear user-visible failure
- SHOULD FIX: likely bug, contract drift, missing verification, or regression risk
- MAY FIX: maintainability or clarity issue with downstream cost

## Review Rules
- Findings MUST come first and MUST include file:line evidence.
- Summaries SHOULD stay brief and secondary.
- Ask First boundaries MUST be called out explicitly when the reviewed change crosses one.
- Code changes MAY happen only if the user explicitly asks for them.
