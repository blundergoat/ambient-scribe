# goat-plan SKILL

4-phase planning workflow.

## Phases
1. **Feature Brief:** High-level goal.
2. **Mob Elaboration:** Detailed design.
3. **SBAO Ranking:** Strategy/Boundary/Action/Output. (Skip for Standard features).
4. **Milestones:** Discrete steps.

## Human Gate
- MUST stop and ask for approval between each phase.
- Compress to single brief for Hotfixes.
